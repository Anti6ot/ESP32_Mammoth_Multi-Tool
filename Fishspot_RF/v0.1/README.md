# 📡 ESP32 Multi-Tool: RF Analyzer & WiFi Portal

Компактный многофункциональный DIY-инструмент на базе ESP32 для образовательного анализа радиочастотного спектра (Sub-GHz) и демонстрации уязвимостей сетей Wi-Fi. Устройство оснащено круглым TFT-дисплеем, слотом для microSD и интуитивным управлением с помощью потенциометра и кнопки.

> ⚠️ **ОТКАЗ ОТ ОТВЕТСТВЕННОСТИ (DISCLAIMER)**  
> Этот проект создан **исключительно в образовательных и исследовательских целях**.  
> - Перехват и анализ радиосигналов должен проводиться только на собственном оборудовании или с явного разрешения владельца.  
> - Функция Wi-Fi портала предназначена для демонстрации механизмов фишинга в контролируемых средах.  
> - Устройство **не поддерживает** клонирование или реплей-атаки (Replay Attacks) на современные системы с динамическим кодом (Rolling Code, AES).  
> Автор не несет ответственности за неправомерное использование данного устройства.

## 🌟 Основные возможности

1. **📻 RF Сканер и Анализатор спектра**
   - Сканирование диапазона 300–928 МГц (315, 433.05, 433.42, 433.92, 868.35 МГц).
   - Отображение уровня сигнала (RSSI) в реальном времени.
   - Автоматический перебор модуляций (2-FSK, GFSK, ASK/OOK) и скоростей передачи для захвата "сырых" HEX-данных пакета.
   - *Примечание: Устройство работает в режиме пассивного приема (Sniffer).*

2. **📶 Wi-Fi Access Point + Captive Portal**
   - Создание точки доступа `ESP32-Portal`.
   - Перехват и демонстрация механизма ввода учетных данных через стилизованную веб-страницу.
   - Автоматическое логирование полученных данных на microSD карту.

3. **💾 Логирование на microSD**
   - Сохранение событий в формате CSV (`/logs.csv`).
   - Просмотр последних записей прямо на экране устройства.

4. **🎛️ Продвинутый UI/UX**
   - Круглый дисплей GC9A01 (240x240) с терминальным/киберпанк-стилем.
   - Навигация по меню с помощью потенциометра (с программным фильтром дребезга).
   - Многофункциональная кнопка (клик, двойной клик, долгое нажатие).

## 📦 Установка программного обеспечения

### 1. Библиотеки Arduino IDE
Установите следующие библиотеки через *Менеджер библиотек* (Sketch → Include Library → Manage Libraries):
- `TFT_eSPI` (автор: Bodmer)
- `OneButton` (автор: Matthias Hertel)
- `SmartRC_CC1101` (версия **V3.0.x** или новее)

### 2. Настройка TFT_eSPI
В файле `User_Setup.h` библиотеки `TFT_eSPI` необходимо раскомментировать и настроить следующие строки для дисплея GC9A01:
```cpp
#define ST7789_DRIVER  // GC9A01 использует тот же контроллер, что и некоторые ST7789
#define TFT_WIDTH  240
#define TFT_HEIGHT 240
#define TFT_CS   5
#define TFT_DC   16
#define TFT_RST  17
#define TFT_BL   21
#define TFT_MOSI 23
#define TFT_SCLK 18
#define LOAD_GLCD
#define LOAD_FONT2
#define LOAD_FONT4
#define SPI_FREQUENCY  27000000
```

### 3. Загрузка прошивки
1. Откройте файл `v0.1.ino` в Arduino IDE.
2. Выберите плату: **ESP32 Dev Module**.
3. Установите скорость загрузки: **921600** или **115200**.
4. Нажмите **"Загрузить"**.

## 🎮 Руководство пользователя

### Навигация по меню
- **Вращение потенциометра**: Перемещение по пунктам меню.
- **Одинарный клик по кнопке**: Выбор пункта / Подтверждение.
- **Двойной клик**: Возврат в главное меню / Выход из режима Wi-Fi AP.

### Режим 1: Wi-Fi AP + Portal
1. Выберите пункт в меню и нажмите кнопку.
2. ESP32 создаст сеть `ESP32-Portal`.
3. При подключении к этой сети с телефона/ноутбука откроется портал авторизации.
4. Введенные данные сохраняются на SD-карту и отображаются на экране.
5. *Двойной клик* для выхода и отключения точки доступа.

### Режим 2: RF Scanner
1. Устройство автоматически сканирует заданные частоты.
2. При обнаружении сигнала (RSSI > -70 dBm) экран показывает частоту и уровень сигнала.
3. При захвате пакета на экране отображается его HEX-дампер.
4. **Потенциометр** в этом режиме позволяет вручную подстраивать частоту в пределах ±0.5 МГц от центральной.
5. Скетч автоматически перебирает скорости (1.2 – 38.4 kbps) и модуляции для максимальной совместимости с неизвестными протоколами.

### Режим 3: View SD Logs
- Просмотр последних записанных событий с карты microSD.
- **Потенциометр** прокручивает список записей.
- **Двойной клик** возвращает в меню.
